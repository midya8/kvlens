READ THE CONTRACT

Less arithmetic is not a speed benchmark.

This is one causal attention block with sinusoidal positions, seeded untrained weights and greedy decoding. Tokens are integer IDs, not meaningful language. There is no residual network, feed-forward stack, training result, production cache or GPU benchmark.

The final-query-only shortcut applies to this block's input projections. It does not let a multilayer transformer skip earlier layer representations required to build later-layer keys and values.

Cache payload is 2 × processed positions × dimension numeric elements. Multiplying by eight gives an ideal packed binary64 payload, not Python object memory, browser heap, peak temporary allocation or measured traffic. A cache reduces recomputation while retaining growing state.

Native guards reject a second prefill into an occupied cache, a cache owned by another model object, malformed state and invalid tokens. Use an independent fork to branch. Weights must stay fixed during a cache's lifetime; mutation of the same model object is not fingerprint-detected. Cache arrays remain mutable and guards are not a security boundary.

All original 28 tests and positive-budget fixture values stay intact. Original Python paths are bitwise equal on the checked inputs. Browser/native agreement is tolerance-tested, not a cross-runtime bitwise guarantee or proof of every possible input.
